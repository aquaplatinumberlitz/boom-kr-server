<p align="center">

LANBoom은 한국 서비스 종료 전 **마지막 한국 클라이언트**(빌드 00967)를 바탕으로 되살린 물풍선 대전 게임입니다.
원작의 맵, 아이템, 캐릭터를 그대로 담았고, **영어·베트남어 지원**, **LAN·인터넷 비공개 방**,
**직접 운영하는 서버** 기능을 더했습니다.

LANBoom은 **무료 커뮤니티 프로젝트**입니다. 이용료도, 유료 재화도, 과금으로 이기는 요소도 없습니다.

## 왜 LANBoom인가요?

- **원작 그대로.** 마지막 한국 빌드의 일반전 맵, 아이템, 캐릭터를 모두 담았고 규칙도 원작과 같습니다.
- **비공개 방은 100% 해금.** 지원하는 모든 아이템, 의상, 캐릭터를 첫 판부터 쓸 수 있습니다.
- **서버가 없어도 됩니다.** 내 PC에서 방을 만들고 친구에게 코드만 보내면 LAN이나 인터넷으로 바로 함께할 수 있습니다. 공유기 포트 개방은 필요 없습니다.
- **다시는 문 닫지 않습니다.** 게임이 내 컴퓨터에서 돌아가므로 누구도 끌 수 없습니다.
- **내 서버, 내 규칙.** 커뮤니티 서버를 직접 열고 계정, 진행도, 해금 방식을 직접 정할 수 있습니다.
- **원하는 언어로.** 33,000줄이 넘는 텍스트를 영어와 베트남어로 사람이 직접 번역했고 기계 번역은 쓰지 않았습니다. 한국어는 원작 그대로입니다.

## 두 가지 플레이 방법

| | 🏠 비공개 방 | 🖥️ 서버 |
|---|---|---|
| **누가 여나요?** | 친구 한 명이 런처에서 방을 엽니다 | 커뮤니티가 PC나 VPS에서 BoomServer를 운영합니다 |
| **계정** | 필요 없음, 이름만 정하면 됩니다 | 서버마다 계정 하나 |
| **아이템·의상·캐릭터** | **100% 해금** | 서버 운영자가 설정 |
| **진행도** | 저장되지 않음 | 서버에 저장 |
| **연결** | LAN 또는 인터넷 방 코드 | S1 초대 코드, 직접 연결이 안 되면 릴레이로 전환 |

**직접 서버를 여나요?** 서버 주인이 모든 권한을 가집니다. 처음부터 전부 해금할지, 플레이로 모으게 할지,
서버에 무엇을 저장할지 모두 직접 정할 수 있습니다.

## 시작하기

1. LANBoom 플레이어 패키지를 **다운로드**합니다. *(2026년 12월 공개 예정)*
2. **런처를 열고** 언어를 고릅니다.
3. **플레이 방법을 고릅니다:**
   - **비공개 방:** 이름을 넣고 **방 만들기**를 누른 뒤 친구에게 코드를 보냅니다.
   - **서버:** S1 초대 코드를 붙여 넣고 계정을 만든 뒤 **게임 시작**을 누릅니다.

자세한 방법은 [플레이어 가이드](docs/player/guide.ko.md)에 있습니다. 서버 운영자용 Windows·Linux 설치 방법도
같은 가이드의 *내 서버 열기 (S1)* 부분에 있습니다.

**사양:** 게임은 Windows 10 또는 11에서 실행됩니다. BoomServer는 Windows나 Linux에서 실행되며 Linux에서는 Docker도 쓸 수 있습니다.

## 자주 묻는 질문

**정말 무료인가요?**
네. LANBoom은 무료 커뮤니티 프로젝트이며 게임 안에서 실제 돈으로 파는 것은 없습니다.

**예전 한국 버전과 같나요?**
네. 서비스 종료 전 마지막 한국 클라이언트를 바탕으로 만들었고 맵, 아이템, 캐릭터, 규칙 모두 원작을 따릅니다.

**포트 포워딩을 해야 하나요?**
아니요. 비공개 방과 S1 서버는 자동으로 연결되고 필요하면 릴레이로 전환됩니다.

**진행도가 사라지나요?**
비공개 방은 진행도를 저장하지 않습니다. 서버에서는 운영자가 데이터를 보관하며 BoomServer에 백업 기능이 있습니다.

**🚧 표시는 무슨 뜻인가요?**
원작 클라이언트에 있는 기능으로, 지금 LANBoom에 옮기는 중입니다. 앞으로의 업데이트에서 추가됩니다.
